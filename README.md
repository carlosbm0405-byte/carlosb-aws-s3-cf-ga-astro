# Popshop

Demo estática de una tienda creada con Astro. El catálogo y la interfaz funcionan en el navegador; el checkout es solo demostrativo.

## Requisitos

- Node.js 26 o superior
- npm

## Desarrollo

```sh
npm install
npm run dev
```

## Build estático

```sh
npm run build
```

Astro genera el sitio listo para publicar en `dist/`.
